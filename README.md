# Display Class

This Java program creates a player object and displays its information.

## Attributes
- `name` (`String`): the player's name, set to "Olise".
- `goals` (`int`): the number of goals scored, set to 100.
- `hasAura` (`boolean`): whether the player has aura, set to true.

## Methods
- `main(String[] args)`: starts the program, creates a `Display` object, and calls `showInfo()`.
- `showInfo()`: prints the player's name, goals, and aura status.
