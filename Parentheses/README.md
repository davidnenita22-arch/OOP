# Parentheses

One Java program covering all three laboratory tasks and the extra-credit `%r` placeholder.

## Files

- `src/Logger.java`: named loggers, shared settings, level filtering, and message formatting (Task 1).
- `src/LogLevel.java`: `TRACE`, `INFO`, `WARN`, and `ERROR`, in increasing order of importance, with their random messages.
- `src/ParenthesesValidator.java`: checks parentheses (Task 2) and logs events during validation (Task 3).
- `src/Main.java`: configures logging and runs the example inputs.
- `output/`: compiled `.class` files generated by `javac`.

## Build and run

Use JDK 17 or newer. From the repository's `OOP` folder:

```sh
cd Parentheses
javac -d output src/*.java
java -cp output Main
```

Run the build command again after editing a source file. `-d output` sends compiled classes to `output` instead of placing them beside the source files. `-cp output` tells Java where to find those classes.

The default minimum log level is `TRACE`. To hide detailed trace messages:

```sh
java -cp output Main INFO
```

Other supported levels are `WARN` and `ERROR`. Use uppercase names. `Main` calls `isValid` for each input; the validator reports events and results through the logger. Final results are logged at `INFO`, so `WARN` and `ERROR` hide them while validation still returns the correct Boolean value.

## How it works

The validator starts with zero unmatched openings. Each `(` increases the count. A `)` decreases it only if an opening is available; otherwise the input is invalid. After processing the string, the count must be zero. Null inputs and characters other than parentheses are rejected; an empty string is valid.

Each logger has its own name. The minimum level and format are static, so every logger shares those settings. The validator's logger is named `Parentheses`.

The format `[%l] %n: %m | %r` prints the level, logger name, message, and a random phrase appropriate to the entry's level. Each enum value stores its phrases, and `LogLevel.randomMessage()` selects one. The logger also supports `%t` for the current time. Random phrases may differ between runs.

Compiled classes are build output and are ignored by Git. Rebuilding recreates them in `output`.
